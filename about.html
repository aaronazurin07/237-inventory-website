About the Developer

This inventory dashboard was designed and developed to demonstrate practical web development skills using HTML, CSS, and JavaScript. The goal of this project is to create a clean and functional command center that allows users to manage inventory efficiently while visualizing stock levels in real time.

The system uses modern browser features such as localStorage for persistent data storage and Chart.js for dynamic data visualization. It focuses on simplicity, usability, and responsive design principles.
